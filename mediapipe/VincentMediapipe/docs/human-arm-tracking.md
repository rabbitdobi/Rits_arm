# 人的整条手臂追踪：肩、肘、腕

与之前的掌心控制模拟机械臂不同，本功能检测人的肩膀、肘部和手腕。
MediaPipe Pose 在原始未镜像 RGB 中定位两侧六个关节，再从同帧对齐到彩色图的
D455 深度读取相机坐标 XYZ（米）。没有增加真实电机输出。

## 运行

双击仓库根目录 `开始手臂三维追踪.command`。若提示 Password，在终端输入 Mac 登录密码。
从距相机约1–1.5米开始调整站位，让两侧肩膀、肘部和手腕都进入画面；距离只是取景建议，
不是精度保证。尽量只有一个人在前景，先展示右臂，慢慢伸直、弯曲、向相机前后移动。
不要遮挡 D455 两侧立体镜头。

无需 O/F/W/空格校准。绿线是解剖右臂，蓝线是左臂。预览镜像，但 XYZ 保持相机坐标：
+X相机向右、+Y向下、+Z向前。右侧表格显示人的关节测量，明确不是机械臂目标。
Q/Esc 保存退出；最多9000个处理帧。关节橙红点表示2D可见但无有效深度。

```bash
.venv/bin/python mediapipe/VincentMediapipe/main.py \
  --realsense --arm-tracking --no-trails --record --max-frames 9000
```

`--camera` / `--video` 也可启用 `--arm-tracking`，但没有深度传感器时只显示2D骨架，
XYZ和3D肘角为空，不拿模型估计的 world Z 当成 D455 实测。
`--unified-preview` 可额外显示旧模拟控制面板；它仍使用掌心位移，不是把人体肘角直接给XM430。

## 数值与缺失处理

- Pose landmark索引：左肩11、右肩12、左肘13、右肘14、左腕15、右腕16。
- 每点要求 visibility 与 presence 都>=0.6、图像坐标有限且在图内；这两个是模型置信指标，
  不能当成坐标精度。
- 沿用原深度采样：中心像素有效、3×3邻域至少60%有效，以中位深度反投影；
  深度跨度不得大于max(3cm,5%深度)。不填洞，不复用旧帧。
- 同帧三点均有深度且上臂／前臂表面点间距离各在0.10–0.65米时，计算肘部弯曲角，
  伸直=0°；也保存以肩为原点的手腕XYZ。范围是宽松异常检查，不是人体长度标定。
- 深度测到皮肤／衣服表面，不是身体内部的关节中心，衣物、遮挡、背景混入和Pose误定位
  都可能造成偏差；通过范围检查也不能称为真实解剖角度或证明准确。
- 选择可见范围最大的Pose，最多检测两个人；无身份锁定。多人场景仍可能切换对象，
  需让测试者占据前景。没有把Pose和手部识别做身份融合。

## 输出

保留原来的手部CSV，新增同名前缀：

- `.human-arm.jsonl`：每帧六点的2D坐标、可见性、深度有效性及原因、XYZ、两侧几何指标。
- `.human-arm.csv`：每帧六行，缺失XYZ为空。
- `--record` 的MP4：镜像骨架和人体关节表格。
- `--depth-samples-every N`：可选原始RGB、深度采样；采样JSON中包括`human_arm`结果。

坐标与已有手部日志用同一帧时间。已有文件不覆盖；sudo运行后新建数据恢复用户所有权。

## 2026-11-20 连续性诊断与改进

诊断录制`fingers-20261120-134638-080449`保存了60张RGB+深度采样。
观察到伸臂时右腕接近或超过图像边界；腕部低置信与深度空洞是两类不同问题。
5个可见但缺深度的采样点，其7×7邻域没有有效深度；没有采用邻域填补或旧帧预测。

新版增加灰色取景框，以及区分出画面、靠边、低可见性、低presence和深度缺失的提示。
日志另存`predicted_image_x/y`与`image_issue`诊断模型输出，不能把这些未通过置信筛选的
预测点当成有效XYZ。正常骨架只绘制有效可见点。

同帧手部模型可辅助腕部：当原Pose腕点没有有效深度，仍要求Pose腕visibility>=0.6、
presence>=0.2且在画内，同时肩肘可见；寻找同侧、handedness score>=0.8的唯一候选手腕。
候选须距Pose腕点不超过20像素，且不超过max(4像素,0.2×前臂图像长度)。
然后在手部模型的腕部像素重新读取严格有效的同帧深度，不沿用Pose像素的空洞深度。
原Pose直接有效时不替换；候选远离、多人匹配歧义、遮挡或深度仍空时不补值。
这是图像邻近匹配，不是跨人身份跟踪，仍需单人前景。

此类点显示`[hand]`并标记`landmark_source=hand_wrist`；保留原Pose失败原因`pose_reason`、
置信度和预测图像位置，同时保存handedness_score。CSV也包含这些字段。
原置信门限适用于Pose直接点；hand-assisted点的visible/valid来自上述独立的手部支持，
不表示原Pose的presence突然变高。`hand_wrist_candidates`记录所有有限候选，
保留重复候选以便审计歧义，不只保存选中的右手。

离线重放默认采用这批原始样本记录的所有候选；旧样本没有全候选时重新运行同配置的
双手检测，而不是仅用保存的选中右手，从而保留唯一候选检查。
可加`--no-hand-assistance`做基线对照。稀疏重放没有现场连续900帧的跟踪上下文，
其结果不等同于现场流的覆盖率。

在相同60张稀疏采样上：Lite基线右臂完整3D为24帧，Full模型为18帧，
双手重新推理+辅助仍为24帧，因此保留默认Lite，并不声称已获得覆盖率或坐标精度提升。
仅用历史选中右手的初步实验得到28帧，但不能验证现场是否有其他候选，未作为正式提升证据。
下一步现场复测同时检查取景改进、辅助来源和直接深度有效性。

## 2026-11-20 平滑显示与来源切换

默认彩色骨架现在是**平滑显示**，灰细线是原始骨架。按 **V** 在原始／平滑骨架之间切换。
右侧XYZ表始终显示原始测量；肘角并列显示 `raw` 和 `filtered`。
这不修改机器人目标、不发送硬件指令，也不校正模型之间的位置偏差。

默认普通平滑时间常数80ms；定位来源变化后240ms内使用180ms时间常数，减轻瞬间切换。
时间权重按采集时间计算，与帧率无关。缺失、置信未通过或非法XYZ时立即清除该点状态；
超过250ms的时间间隔重置全部状态。当前原始几何被判为异常时不输出有效平滑肘角，
也不会靠旧数据补出完整三维手臂。恢复检测时从当前测量重新开始。

JSON的原有`points`和`arms`继续保存原始数值；新增`stabilized`，标明
`kind=filtered_visualization`、参数、逐点来源切换和重置状态。
`.human-arm.csv`仍只写原始测量，不混入平滑XYZ。
原始2D可见但深度缺失时可以显示当前2D骨架，XYZ和三维角仍为空。

调整时间常数或完全关闭：

```bash
.venv/bin/python mediapipe/VincentMediapipe/main.py --realsense --arm-tracking --arm-smoothing-ms 80 --record
# --arm-smoothing-ms 0 禁用普通和来源切换平滑
```

平滑会增加延迟，也不会消除持续的位置偏差。它不能提高缺失点覆盖率，
不能把未验证的衣服表面坐标变成真实关节中心，也不能用于宣称物理精度提高。

`Saved N frames`并提示录制正常结束。按Q/Esc为`user_exit`，录像结束为`video_end`。
画面在配置了帧数上限时显示预计自动保存／结束倒计时（按当前处理帧率估算，不是精确计时）。
退出报错仍按错误处理，不把异常伪装成正常完成。

诊断轮`fingers-20261120-142444-004455`完整保存900帧和90张原始采样后结束，
日志无异常，也没有找到对应Python崩溃报告。90张采样中右腕76张中心深度为空，
其中68张的当前有效肘部Z小于0.55米。RGB中手腕朝镜头伸近，深度图对应区域整体为空；
近距离可测范围不足是与这些证据一致的解释，不能据空洞反推出实际腕部距离。

现在在腕部中心空洞／稀疏且当前肘部深度<0.55米时显示
`Wrist may be too close: move the whole arm farther back`。

0.55米是操作提醒的保守启发阈值，不是D455硬件最小距离，也不是缺失手腕的测量。
原腕部XYZ仍为空，不做填补。请整体后退，让伸臂时手腕仍与镜头保持距离，避免只后退肩膀后又把手伸到镜头前。

## 最近两秒数据可用率

右侧表格顶部现在显示右臂三点深度齐全的采样比例，例如
`Right depth 3/3: 96% / last 2.0s`。这是原始测量的可用率，
不是坐标正确率、置信概率或物理精度。数字同时要求肩、肘、腕的当前深度有效，
几何检查通过率另存在JSON中，不用平滑值补高覆盖率。

`quality`字段含最多2000ms内的样本数、实际观察跨度、深度齐全比例、
几何通过比例及本轮累计计数。至少连续10帧且跨度>=1000ms才显示百分比，
之前显示warming up；显示实际1.0–2.0s跨度。帧间隔>250ms时清空近期窗口，
重新预热，不让旧数据看起来像刚刚连续采到。累计计数不会随窗口重置，
每帧保存的是独立快照。正常结束时终端打印全轮深度齐全率和几何通过帧数。

调整站位时可参考这个比例：先确保整臂入镜并保持手腕距离，
再看近期齐全率能否持续较高；即使为100%，仍不能证明坐标或解剖角准确。
