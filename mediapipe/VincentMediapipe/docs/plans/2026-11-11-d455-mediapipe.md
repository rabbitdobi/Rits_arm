# D455 + MediaPipe integration

Authorized scope: connect the already working D455 to the existing right-hand
tracker; show and export metric positions without ROS or motor commands.

1. Add `realsense_source.py`: SDK source, depth-to-color alignment, frame metadata,
   raw landmark pixel sampling and SDK deprojection. Unit tests first for scale,
   holes, depth edges, invalid/out-of-range landmarks, no mirror/no smoothing mix,
   all 21 joints and a palm-center proxy, and CSV loss rows.
2. Add mutually-exclusive `--realsense`, optional positive `--max-frames`, metric
   `.depth.csv` and `.depth.json` outputs in main.py. Preserve normal camera/video
   CLI and legacy CSV columns. Optional JSON gets a depth object. Side-by-side
   mirrored RGB/depth preview shows fingertip XYZ in meters and flexion when
   requested. Metric sampling always uses original unsmoothed/unmirrored landmarks.
3. Add launcher and guide. Run full suite, saved RGB/raw-depth fixture integration,
   independent review, and live D455 capture/MP4 validation after Terminal USB
   administrator access. Restore only newly created outputs to user ownership.

Depth validity: require a positive finite center pixel, at least 60% positive
finite samples in a clipped 3×3 patch, and patch depth range <= max(0.03m,5% of
median). Median depth is used at the landmark ray; this is an approximation, and
does not guarantee the depth belongs to a fingertip at a boundary. Do not fill
holes or reuse past values. Nonfinite XYZ is rejected. Coordinates are D455
unmirrored color optical frame (+X right,+Y down,+Z forward), not MediaPipe world
coordinates or robot coordinates. Palm center is the image-space mean of 0/5/9/13/17.

In D455 mode, optional control flexion remains model-based but palm distance uses
sensor depth; monocular calibration is disabled. Output paths must be distinct
and absent before device access. Tracking loss is recorded, never a zero command.
